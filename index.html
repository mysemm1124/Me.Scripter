    사용법

    ₩씬 추가. 줄 맨 앞에 치면 씬 제목이 되고 번호는 자동으로 매겨져. 중간에 씬을 넣거나 지워도 다시 번호가 매겨짐. (영문 상태의 \ `도 같아)
    -대사. 줄 맨 앞에 치고 이름 → Space / Tab / Enter 누르면 대사 칸으로 넘어가. 이름은 설정에 따라 자동 굵게.
    ( )지시문은 따로 형식 없이 대사 안에 그냥 써. 밥 먹었어? (웃으며) 그럼 됐어.
    Enter씬 → 지문, 이름 → 대사, 대사 → 지문으로 자동 전환. 빈 줄에서 누르면 지문으로 돌아감.
    ⇧Enter같은 인물 대사 이어서 쓰기
    ⌫줄 맨 앞에서 누르면 그 줄을 지문으로 되돌림
    ⌘Z기호가 실수로 변환됐으면 바로 되돌리기 → 기호가 글자로 남아
    ↑↓ Tab이름 칸에서 자동완성 고르기
    Ctrl1~4현재 줄 형식 바꾸기 (씬·지문·이름·대사)
    ＋ 퇴고하기지금 작품을 복사한 퇴고본을 만들어서 왼쪽에 원본, 오른쪽에 퇴고본을 나란히 띄워. 고친 줄은 색으로 표시되고, 스크롤하면 원본도 같은 장면으로 따라와. 원본은 그대로 보존돼.
    붙여넣기메모장에 ₩거실 / 밤, -지우 밥 먹었어? 식으로 써 둔 걸 붙여넣으면 형식이 자동으로 바뀜. 이 편집기에서 복사한 것도 형식이 유지돼.

    게스트 모드에선 글이 이 브라우저에만 자동 저장돼. 로그인하면 계정에 저장돼서 다른 기기에서도 이어서 쓸 수 있어. 혹시 몰라 따로 보관하려면 내보내기 → 백업.
