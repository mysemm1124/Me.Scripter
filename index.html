    사용법

    ₩씬 추가. 줄 맨 앞에 입력하면 씬 제목이 되고 번호가 자동으로 매겨집니다. 중간에 씬을 추가하거나 삭제해도 번호가 다시 정리됩니다. (영문 입력 상태의 \ `도 같은 기능입니다)
    -대사. 줄 맨 앞에 입력한 뒤 이름 → Space / Tab / Enter 누르면 대사 칸으로 넘어갑니다. 이름은 설정에 따라 자동으로 굵게 표시됩니다.
    ( )지시문은 별도 형식 없이 대사 안에 함께 작성합니다. 밥 먹었어? (웃으며) 그럼 됐어.
    Enter씬 → 지문, 이름 → 대사, 대사 → 지문으로 자동 전환됩니다. 빈 줄에서 누르면 지문으로 돌아갑니다.
    ⇧Enter같은 인물의 대사를 이어서 작성합니다.
    ⌫줄 맨 앞에서 누르면 해당 줄을 지문으로 되돌립니다.
    ⌘Z기호가 의도치 않게 변환되었을 때 되돌리면 기호가 글자로 남습니다.
    ↑↓ Tab이름 칸에서 자동완성 항목을 선택합니다.
    Ctrl1~4현재 줄의 형식을 변경합니다. (씬·지문·이름·대사)
    퇴고 모드왼쪽에 저장된 퇴고본, 오른쪽에 지금 작업 원고를 나란히 표시합니다. 처음 퇴고 모드를 켜면 그때의 원고가 v.1(원본)으로 저장되고, 이후에는 ‘퇴고본 저장’을 누를 때만 v.2, v.3 …이 생깁니다. 메인 모드와 퇴고 모드는 같은 원고를 편집하므로 언제든 오가도 작업이 이어집니다. ‘메인 모드에서 편집하기’를 누르면 왼쪽 버전 내용을 작업 원고로 불러옵니다.
    트리트먼트작품마다 줄글로 트리트먼트를 작성합니다. AI 요약을 켜면 오른쪽에 존 트루비 7단계 기준으로 작성된 내용이 정리됩니다.
    메모글을 드래그하면 나타나는 버튼으로 하이라이트와 메모를 남길 수 있습니다. 왼쪽 목록에서 바로 이동·수정·삭제할 수 있고, 휴대폰에서는 읽기 전용으로 열려 메모만 남길 수 있습니다.
    붙여넣기메모장에 ₩거실 / 밤, -지우 밥 먹었어? 형식으로 작성한 글을 붙여넣으면 자동으로 변환됩니다. 이 편집기에서 복사한 내용도 형식이 유지됩니다.

    게스트 모드에서는 이 브라우저에만 자동 저장됩니다. 로그인하면 계정에 저장되어 다른 기기에서도 이어서 작성할 수 있습니다. 별도 보관이 필요하면 내보내기 → 백업을 이용해 주세요.
